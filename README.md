# Revelation: The Book of Return / 默示录：归途之书

基于 [秋枫白桦框架](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework) 的《Degrees of Lewdity》剧情模组。

模组以 `RBR` 为根模块，罗宾神殿线是目前第一个独立的 `RobinTemple` 模块。它以旧版 Maplebirch 模组为蓝本重制：从罗宾房间谈起加入神殿，在神殿宿舍准备并参加考核，此后一起承担神殿工作。罗宾可以在原版守夜试炼前陪伴玩家。满足关系与服务条件后，可以向约旦申请承诺仪式。神殿路线保存在当前存档的 `$RobinTemple` 中。

需要 DoL 0.5.12.13 或更新版本、秋枫白桦框架 5.2.0 或更新版本。可与枯木逢春同时加载，罗宾在枯木逢春中的经济与其他剧情状态由该模组自行管理。

本仓库处于开发阶段，剧情和游戏内表现尚需实机核对。
