## 安装与前置

1. 准备支持 SugarCube 2 ModLoader 的 **DoL 0.5.12.13**。
2. 加载[秋枫白桦框架](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework)，满足 `maplebirch >= 5.2.2`，并安装模组包声明的其他依赖。
3. 从 [Releases](https://github.com/MaplebirchLeaf/Revelation-The-Book-of-Return/releases) 加载 `revelation-the-book-of-return-*.modpack`。
4. 在框架模块管理中启用根模块与想使用的子模块，修改开关后先保存游戏，再按提示重载。

枯木逢春是可选联动模组，不是基础剧情的必需前置。本版本以 DoL 0.5.12.13 为目标，剧情入口仍要满足原版身份、衣着、人物关系、状态与日程条件。

## 模块与游戏指南

| 模块           | 内容                                                     |
| -------------- | -------------------------------------------------------- |
| `RBR`          | 归途之书根模块，管理子模块的依赖                         |
| `RobinTemple`  | 罗宾入殿、神殿日常、承诺仪式、混乱誓约及共同检查         |
| `TempleChoir`  | 约旦安排的唱诗工作、歌唱技能、领唱资格与月度津贴加款     |
| `TempleDuties` | 神殿职务、旧资料室修缮、调查、司祭任命与同伴晋升         |
| `LostLamb`     | 凯拉尔庄园梦境、两种分支与主结局、醒来后的交谈和梦痕特质 |

关闭 `RBR` 会停用归途之书的全部子模块。唱诗班可以单独开启，不需要先让罗宾加入神殿。

同时安装并启用带模组提示功能的**枯木逢春**时，在侧边栏打开**模组提示**，可查看归途之书的详细章节。目录支持章节跳转、搜索和右侧模块复选框。四栏指南按入口、步骤、日程、收益与中断处理组织；也可直接阅读仓库中的[中文指南](src/assets/hint/CN)。当前进度见**游戏日志**中的罗宾、唱诗班、神殿职务与迷途羔羊记录。已结束的一次性任务不再保留待办提醒。

## 1.2.0 当前内容

### 罗宾神殿路线

PC 通过原版入殿试炼、衣着完整且压力未满，罗宾爱意足够且能够正常活动后，从**孤儿院 → 罗宾的房间**谈起神殿。陪同见约旦、预约并准备纯洁试炼，完成考核后开放神殿宿舍的交谈与更衣处。**罗宾的床铺**与周六留宿须罗宾再通过苦难审判，达到修士或修女等级。贞操器具只改变邀请时的开场对话。

加入后可一起值班、准备弥撒、祈祷、送礼与散步，也有夜间陪伴和医院支线。罗宾的信仰、动摇、贡献与共同经历会影响后续，对话与入口遵循上学、神殿事务及其他工作日程。

关系和神殿贡献满足条件后，可申请评估并举行承诺仪式。共同苦难审判保留原版的守夜过程。承诺后仍有月度检查、破誓后的共同净化与器具管理，不能只靠增加爱意跳过流程。贞操带与护肛板需先申请，再在约旦有空时陪同办理。

同住房产中也可谈起神殿和混乱誓约，结束交谈后返回同一住处。共同活动须在罗宾下项事务前完成。

### 混乱誓约

这是一条与原版**异教仪式、绝望轮回和水下幻境**相连的后期分支。PC 与罗宾、悉尼已有深厚关系和一份承诺时，可以从两人的私下谈话开始调查，在湖畔勘查，再于合适的血月夜前往湖底废墟。

悉尼须保持堕落立场，承诺顺序决定是否还需完成其堕落仪式。三人都不能佩戴贞操器具，正式仪式还要满足关系、欲望、誓言与身体条件。初次调查不等于同意仪式，见证异常后可返回，再分别谈妥，也可尝试有诡术检定与关系代价的当晚话术。

完成后获得**混乱誓约**并连接第二份承诺，后续共同检查随之变化。追猎、天气、湖面与人物状态会影响出行，途中也可能中止。详细前置与分支步骤见游戏指南。

### 神殿唱诗班与歌唱

PC 成为适用的神殿成员后，在**神殿大厅**向约旦询问唱诗班。加入后可每日练习换气、音准或合唱，周日参加弥撒中的三段唱诗，按当前能力选择跟唱、和声或领唱。

新增的**歌唱**技能使用原版技能等级显示。哈比转化改善发挥，疲劳与醉酒会降低表现。基础歌唱达到 **B 级**后，还须完成规定的练习、工作及表现要求，才会得到约旦的领唱许可。

完整唱诗累积津贴加款，**通过月度检查且原版津贴获准发放时一并领取**，周日结束不会立即发钱。中途退出会占用当天弥撒机会，也不会取得本次加款。日志可查看练习、唱诗、领唱与待领金额。

### 神殿职务与司祭任命

PC 加入神殿后，从**神殿大厅 → 职务簿**向约旦申请职务。清点物资、晾毯子、阅读旧资料或出门调查，取得报酬、恩典与技能练习。旧资料室的屋顶和书架可以分别出资修缮，完工后缩短查阅时间。

三项调查由追查敲击声逐渐走向根须与触手遭遇。路线、资料、借来的装备以及 PC 的历史、科学、诡术、体能等能力会影响准备与负担；如实解决后向约旦汇报，领取一次性报酬。

成为修士或修女、完成原版营救、把金色长矛交还神殿，并保持誓言与月检状态后，可接受**下层门前的守望**。两场非人战斗之间还要护住灯火、辨认应答和归路。通过后回暖室包扎，再接受约旦主持的任职审查与司祭任命。

悉尼和罗宾须本人同意、完成各自练习，由 PC 同行协助护灯和应答，取得自己的守望资格并面谈。PC 可以共同受任，也可在成为司祭后继续协助。晋升保留学校、工作、同住日程及神殿誓言。主教的密封便条、圣体匣与凯拉尔调查为可选后续，不是晋升前置。

### 迷途羔羊：凯拉尔的庄园梦境

发现庄园的圣体匣、听完凯拉尔对父母异变那晚的回忆，并经历原版首次庄园睡眠事件后，在**凯拉尔房间**选择「躺下休息一会儿」，再闭眼进入。

在梦中作为旧日的凯拉尔行动，从悉尼来访的下午走向失约、碎玻璃的夜晚与后来的生活。疑心、不安、引起的注意、行动顺序与梦中时刻决定能听见什么、是否被发现，以及如何继续。失败有对应的补救，游戏与检查不能反复刷数值。

**先完成两个分支，再开放主结局。**可随时醒来并从中断处继续，完成结局后再次进入可直接选择另一种梦。现实每次进入只经过三十分钟，醒来恢复现实外貌、物品、钱、天气和人物状态。梦中日期、线索与进度可在日志查看。

完成主结局并醒来，获得成就**迷途羔羊**与特质**梦痕**，睡眠中的持续噩梦压力减少 25%。之后晚间可与凯拉尔谈一次那个梦，回应随好感与嫉妒变化。梦境不替原版确定父母异变的真相，也不会让悉尼与凯拉尔自动和好。

## 与枯木逢春联动

| 启用内容             | 联动                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 罗宾拓展             | 家教、摊位、店铺与住院影响神殿日程，神殿收入接入罗宾账本                         |
| 原版增强             | 不屈意志参与守夜与混乱誓约回应                                                   |
| 更多恋人与社交栏头像 | 可按意识等级保留罗宾和悉尼的恋人关系，双承诺仍须完成仪式                         |
| 金融：房产与捐款     | 同住房产影响回家与留宿；资料室修缮使用既有付款渠道，收据与食物、毯子基金分别记账 |
| NPC 侧边栏立绘       | 神殿见习服、修士服／修女服及睡衣随场景切换                                       |
| 更多转化             | 完全马、鲸或渡鸦转化的可见部位提供神殿长椅互动                                   |

完全哈比转化的唱歌互动也可练习歌唱。联动按实际启用模块与当前人物状态判断，未安装枯木逢春时仍可进行基础神殿路线和唱诗工作。
