# 默示录：归途之书

[![Game](https://img.shields.io/badge/Game-Degrees%20of%20Lewdity-purple)](https://gitgud.io/Vrelnir/degrees-of-lewdity)
[![Framework](https://img.shields.io/badge/Framework-maplebirch-blue)](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework)

基于秋枫白桦框架的 **Degrees of Lewdity** 剧情模组，围绕神殿生活、人物关系与旧日谜团展开。

**[下载模组](https://github.com/MaplebirchLeaf/Revelation-The-Book-of-Return/releases/latest)** · [更新记录](https://github.com/MaplebirchLeaf/Revelation-The-Book-of-Return/releases) · [问题反馈](https://github.com/MaplebirchLeaf/Revelation-The-Book-of-Return/issues)

## 内容概览

| 内容         | 简介                                                 |
| ------------ | ---------------------------------------------------- |
| 罗宾神殿路线 | 陪伴罗宾入殿，经历日常、试炼与承诺。                 |
| 混乱誓约     | 与罗宾、悉尼共同调查湖底的异象，延续承诺之后的故事。 |
| 唱诗与演唱   | 练习歌唱、参与弥撒，也可在小镇演出。                 |
| 神殿职务     | 承担工作、修缮资料室、追查案件，并接受司祭任命。     |
| 迷途羔羊     | 走入凯拉尔旧日的庄园梦境，探索过去与醒来后的回响。   |

各部分可在框架模块管理中选择启用。

## 安装

面向中英文原版 **DoL 0.5.12.13**，需要 SugarCube 2 ModLoader 和[秋枫白桦框架](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework) **5.2.2 或更新版本**。

1. 从下载页取得 `.modpack`，添加到 ModLoader。
2. 满足安装包声明的前置依赖。
3. 在框架模块管理中启用归途之书及所需内容，按提示重载。

[枯木逢春](https://github.com/MaplebirchLeaf/Deadwood-Reblooms)是可选联动，提供房产、日程、宴会、转化与人物立绘等联动内容。

## 游戏指南

详细入口与玩法见[中文指南](src/assets/hint/CN)。配合枯木逢春，也可在游戏侧栏的**模组提示**中阅读；路线和任务进度可查看**游戏日志**。
