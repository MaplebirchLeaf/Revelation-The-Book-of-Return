# Revelation: The Book of Return / 默示录：归途之书

A story mod for [Degrees of Lewdity](https://gitgud.io/Vrelnir/degrees-of-lewdity) built on the [Maplebirch Framework](https://github.com/MaplebirchLeaf/SCML-DOL-maplebirchFramework).

`RBR` is the root module. `RobinTemple` is its first independent story module, rebuilding the Robin temple route from an older Maplebirch mod. The route begins in Robin's room, then follows Robin's decision, assessment, temple duties, vigil, and promise ceremony. Progress is stored in `$RobinTemple` in the current game save.

Requires DoL 0.5.12.13 or later and Maplebirch Framework 5.2.0 or later. The mod can be loaded alongside Deadwood Reblooms. Robin's business and other Deadwood story state remain in that mod.

This project is in development. The route still needs full in-game review.
