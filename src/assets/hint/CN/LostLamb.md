# 迷途羔羊 · 庄园回忆

在凯拉尔的房间休息，梦见庄园的过去。你将在梦中作为年幼的凯拉尔行动，寻找那晚的记忆。

### 怎样入梦

先在庄园发现圣体匣，与凯拉尔谈过父母的事，并经历首次留宿。等凯拉尔有空时，到**庄园 → 凯拉尔房间**，选择「**躺下休息一会儿**」，再选「**闭上眼睛 (0:30)**」。

每次入梦花 **30 分钟**。梦中有自己的时间，醒来后回到入梦时的现实。衣物、物品与金钱也会恢复。

### 怎样推进

初次入梦先与悉尼度过一个下午。之后来到门口，可以选择花园或厨房的声音。

| 路线       | 可以做什么                                                     |
| ---------- | -------------------------------------------------------------- |
| 花园       | 留意游戏规则、敲门声与画上的门，尝试不同的玩法，寻找下楼的路   |
| 厨房       | 听大人谈话，询问访客与父母的变化，帮忙准备晚饭                 |
| 自己的声音 | 完成前两条路线后开放。寻找食物、照顾父母、清理退路，并向外求助 |

梦中的选择会改变三种感受：

- **疑心**：帮助你发现矛盾，也可能让求助更难。
- **不安**：影响面对危险时的表现。吃东西、喝水或准备休息的地方能缓解它。
- **注意**：表示你引起了多少注意。吵闹和冲突会让屋里的东西更容易发现你。

选项旁会显示检定与变化，日志也会记录线索。答应保密等承诺会影响之后的梦，违背承诺可能引来危险。

### 醒来与继续

- 「**暂时醒来**」会保留当前梦境，下次休息时继续。
- 在结局选择「**睁开眼睛**」后，记录这条路线的结局。下次入梦从门口重新选择。
- 重走完成过的路线时，会重新开始这条梦。其他结局与初次下午留下的经历保留，新的承诺会替换这条路线原来的决定。

### 奖励与后续

完成主结局并醒来，可获得「**迷途羔羊**」成就与「**梦痕**」特质。梦痕使睡眠中噩梦造成的持续压力增加降低 **25%**。

之后在 **18:00 起**，到凯拉尔的房间选择「**和凯拉尔谈谈那个梦**」。可以陪伴、谈起那一晚，或留出一些空间。梦里的承诺与凯拉尔的嫉妒会影响回应。交谈完成后，之后的房间描写也会有所变化。

还可以向这些人打听旧事：

- **悉尼**：在学校图书馆、成人商店或神殿祈祷时，选择「轻叩桌上的暗号」。一起送凯拉尔回过庄园时，会谈起那次见面。
- **格威岚**：营业时选择「向格威岚打听旧事」。之前谈过凯拉尔父母的事，会有不同回应。
- **主教**：听过庄园往事的完整说明后，在告解室或神殿职务的交谈中选择「询问封死的宅邸」。
