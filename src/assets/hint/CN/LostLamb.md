### 前置条件与推荐顺序

启用「迷途羔羊」，在**凯拉尔的庄园 → 凯拉尔房间**进入梦境。

- 已在庄园发现**圣体匣**。
- 已问过凯拉尔父母的事，听完父母异变那晚的回忆。
- 已经历原版**首次庄园睡眠事件**。
- 凯拉尔仍能正常活动，当前不在战斗、其它演绎或重放场景中。

推荐顺序：**调查庄园、听凯拉尔回忆 → 房间里休息 → 体验共有下午 → 完成两种分支梦境 → 回来进入主结局 → 醒来后与凯拉尔交谈**。

听悉尼谈过童年来访、听过主教的说法，或听格威岚谈及凯拉尔父母，会补充对应回忆。

### 入口在哪里，怎样开始

在凯拉尔房间选择「**躺下休息一会儿**」，看完前情后，再选择「**闭上眼睛 (0:30)**」。仅打开前情页不会开始梦境，也不会消耗这三十分钟，可以「坐起来」返回房间。

闭眼后，你作为旧日的凯拉尔行动。现实先经过三十分钟，之后的行动耗时、日夜变化与天气都属于梦境。梦里经过多日，醒来时不会让现实也过去多日。

首次进入会与悉尼度过来访的下午。可以一起画画、去花园、找吃的，再等到晚饭与道别。这里的选择会留下后续可能用到的经历，**不需要把所有活动都做完才能继续**。

### 日志、提示与三种感受

梦中打开**游戏日志**，查看梦中日期、第几天、当前线索与三种感受。三种感受随当前梦境里的行动变化。

| 感受       | 主要影响                                         | 怎样留意                                               |
| ---------- | ------------------------------------------------ | ------------------------------------------------------ |
| 疑心       | 辨认矛盾、核对讲述，有时也妨碍开口寻求帮助       | 留意声音、顺序与物品，**不是始终越高越好**             |
| 不安       | 安静等待、稳住呼吸、靠近危险与完成细致动作       | 吃饭、喝水、整理安全位置可缓解，硬撑可能使它加深       |
| 引起的注意 | 偷听、隐蔽行动与经过危险区域时，是否被发现或靠近 | 喊人、争执或声响引人注意，日常事务与安静行动可帮助避开 |

普通行动在链接旁标明耗时。检定选项会显示所检查的感受，彩色提示预告本次变化。开启原版**隐藏数值**时，这些提示与日志中的数值也会隐藏。

<span class="teal">检定看的是你点击前的状态。先前选择、准备顺序与当前时刻都会起作用。失手会进入另一段处境，仍有补救或继续的办法，不必因一次失败重新开始。</span>

### 两种分支梦境与主结局

悉尼离开后的门口有两种分支。**两种都完成，主结局的第三个选择才会出现**，完成顺序不限。到达结尾后，选择「睁开眼睛」回到现实。

| 门口选择             | 这条梦境围绕什么展开                             | 进入前应知道什么                                       |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------ |
| 跟着悉尼的声音去花园 | 来访、失约、暗号，以及不断重复的下午             | 游戏里的约定与敲击声会成为辨认异常的线索               |
| 靠近厨房里的谈话声   | 偷听大人、追问来客、尝试拼出父母变化的解释       | 偷听时机、引起的注意和疑心会改变局部经过               |
| 留下来听自己的声音   | 碎玻璃的夜晚，以及此后吃饭、求助与安排退路的生活 | 须先完成两种分支，准备与自我照料可提供更稳妥的后续动作 |

三条梦境分别保留结局记录。

### 花园分支：游戏、暗号与重复的下午

| 地点与活动     | 条件与做法                                                     | 影响与后续                                         |
| -------------- | -------------------------------------------------------------- | -------------------------------------------------- |
| 雨天的室内游戏 | 纸牌与捉迷藏各做一次，之后才能继续听楼下的动静                 | 纸牌影响疑心与注意，捉迷藏考验能否等完整个暗号     |
| 翻看书里的图画 | 先玩过纸牌，而且已开始留意不对劲之处                           | 有助于核对故事，未出现时可以继续其它活动           |
| 门外的敲击声   | 先听清，再决定靠近哪扇门                                       | 疑心影响辨认，先前记住的停顿会在后面派上用场       |
| 重来的下午     | 换杯子位置、让悉尼决定规则都做过后，可以检查下楼的路           | 改变疑心与注意，进一步检查画里的门另有经历条件     |
| 木棚两侧的声音 | 记得正确暗号、能留意异常时，可听清两边。听错也有练习补救的机会 | 没有这些准备仍可选择透着白昼的一侧，继续到分支结尾 |

游戏与检查不能无限重复刷取感受。安静移动、观察固定物品和保留停顿，与直接追着声音走，会带来不同的经过。成功与失手的经过都能继续到分支结局。

### 厨房分支：偷听、来客与解释

| 地点与时段         | 条件与做法                                                 | 影响与后续                                                   |
| ------------------ | ---------------------------------------------------------- | ------------------------------------------------------------ |
| 实验室附近的楼梯口 | 先找地方听一听，听过一段后才能追听没说完的话               | 贴近门能听到更多，也更引人注意。被发现时仍有解释和收敛的办法 |
| 隔着连通门听       | **17:00–17:30** 才有机会，包含 17:00，不包含 17:30         | 坐台阶、拿鞋及返回也耗时，想听门内谈话应先安排顺序           |
| 抄下听到的话       | 根据当前疑心，尝试给没听清的地方留空                       | 未能留空时仍可划掉自己补出的答案，后面能保留这种矛盾         |
| 再次准备晚饭       | 热食物、洗杯子或拿碗至少做一项，才可把晚饭端到门口         | 热食物有助于稳定情绪，洗杯子能继续听谈话但会引人注意         |
| 趁谈话洗杯子       | **16:00–17:00** 开放，包含 16:00，不包含 17:00             | 其它准备和返回会耗时，过时仍有热食物、拿碗等办法继续         |
| 靠近应答的房间     | 不安较轻时更能留下看清，退开后仍能扶墙呼吸、数着木板往前走 | 成功与失手提供不同的后续动作，都可以继续追问                 |

### 主结局：照料自己、求助与留出退路

主结局开放后，从门口选择「**留下来听自己的声音**」。故事继续到父母让你早睡的晚上，以及之后的生活。

| 活动                 | 怎样做                                                     | 会改变什么                                                 |
| -------------------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 夜里等待、稳住呼吸   | 喊父母或保持不动，再尝试在被子下留出呼吸空间               | 不安影响是否能稳住，失手时仍可守住空隙等到早晨             |
| 先吃饭或先分好食物   | 先让自己的手不再发抖，或先做好全部人的份量                 | 影响送食物时的状态，盘子被碰到仍能放手抽回袖子             |
| 清理、喝水与看花园   | 沿墙清出窄路、喝水洗手或查看大门，再决定出去               | 窄路能通向街上，先前安静送过食物也可能提供花园路径         |
| 向外面的人求助       | 疑心影响能否直接说清，说不出口也可指给对方看碎窗           | 之后仍有留下联系方式、再次求助的机会                       |
| 第二天端早餐         | 端齐早餐或腾出一只手                                       | 决定厨房里怎样挡住动静，腾出的手还可能帮助之后稳住门框     |
| 留消息与整理休息位置 | 先说清接应地点，才能继续经过大厅。休息与观察是可选额外准备 | 整理过休息位置，或先前腾出过一只手，可提供较慢但更稳的动作 |

### 暂时醒来、继续与重新体验

- **还没到结局**：随时选「暂时醒来」。再次闭眼，回到中断的位置，保留本轮感受与已做过的选择。
- **已经到结局**：选「睁开眼睛」。再进入会回到悉尼离开后的门口，可选另一种梦，不必重做整个共有下午。
- **重玩已完成的路线**：结局记录保留，本轮感受与路线内选择重新开始，共有下午留下的经历仍可使用。
- **醒来后的状态**：恢复闭眼后的现实时间、外貌、衣装、物品、钱、天气与人物状态，梦境进度单独保留。
- **保存或停用模块**：可在梦中保存并继续。停用模块后读取梦中存档，会先恢复现实状态，保留已记下的进度。

<span class="teal">每次闭眼进入都会消耗现实三十分钟，继续中断的梦也一样。梦中走过的日子不会额外推进现实的房租、工作或人物日程。</span>

### 奖励与醒来后的凯拉尔

两种分支完成后，完成主结局并**睁开眼睛**，获得成就「**迷途羔羊**」和特质「**梦痕**」。成就沿用原版对作弊、调试及游戏模式的限制，特质按剧情完成记录生效。

**梦痕使睡眠中因噩梦持续增加的压力减少 25%。**包括普通睡眠与荒原绑架后的睡眠，不减少可操作噩梦里的战斗或剧情压力。重玩不会叠加效果，停用「迷途羔羊」后效果停止。

主结局之后，**18:00 起**，凯拉尔在房间且能够正常活动时，会出现「**和凯拉尔谈谈那个梦**」。可在此后晚间再来。

| 选择                     | 耗时   | 效果                                   |
| ------------------------ | ------ | -------------------------------------- |
| 陪凯拉尔坐一会儿         | 十分钟 | 增加凯拉尔好感，缓解你的压力           |
| 问起凯拉尔记得的那个夜晚 | 十分钟 | 增加凯拉尔好感，缓解你的压力           |
| 想独自待一会儿           | 五分钟 | 留出安静空间，不改变人物关系与压力数值 |

三项只能选一项，**现实交谈只结算一次，重玩梦境不会重置**。仅打开谈话页、尚未选择时，可以离开后再谈。凯拉尔的回应及日后房间的简短描述随话题、好感与嫉妒变化，高嫉妒的回应优先。

### 常见问题

| 问题                       | 核对顺序                                                           |
| -------------------------- | ------------------------------------------------------------------ |
| 房间没有休息入口           | 模块是否启用、圣体匣是否发现、父母回忆是否听完、首次睡眠是否经历过 |
| 只能选两种梦               | 两个分支都完成后，再回到门口，才会出现主结局入口                   |
| 书、画里的门或暗号选项没有 | 检查之前的游戏与准备，再看当前感受和对应检定经过                   |
| 门内偷听或洗杯子不见了     | 查看梦中时刻，这两项有时间窗口。过时仍可用其它行动继续             |
| 刚选失败，是不是要重开     | 继续看当前处境，失败后的解释、退避或准备同样能推进                 |
| 做过的游戏无法再做         | 这是本轮已完成的活动，按其它选项继续                               |
| 醒来后没有成就或特质       | 是否完成主结局并睁眼。仅两个分支不够，作弊等模式另有原版成就限制   |
| 凯拉尔没有谈梦的选项       | 主结局是否完成、是否已作出一次谈话选择、是否已到晚间且人在房间     |
