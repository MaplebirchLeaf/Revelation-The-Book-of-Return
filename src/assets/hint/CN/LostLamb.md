### 入口与推荐顺序

启用「迷途羔羊」，在**凯拉尔的庄园 → 凯拉尔房间**选择「**躺下休息一会儿**」。入口需要：

- 已发现庄园的**圣体匣**。
- 问过凯拉尔父母的事，听完异变那晚的回忆。
- 经历过原版首次庄园睡眠事件。
- 凯拉尔能够正常活动，当前没有战斗、其他演绎或重放场景。

推荐顺序：**调查庄园、听回忆 → 休息并闭眼 → 度过悉尼来访的下午 → 完成两种分支梦境 → 完成主结局 → 醒来后与凯拉尔交谈**。

听悉尼谈童年来访、听主教揭密，或听格威岚谈凯拉尔父母，会补充对应回忆。

### 梦中的时间与感受

前情页可以直接「坐起来」离开。选择「**闭上眼睛 (0:30)**」后才开始梦境，并消耗现实三十分钟，继续中断的梦也一样。

梦里你作为旧日的凯拉尔行动。之后的日期、天气和行动耗时属于梦境，醒来恢复闭眼后的现实状态，不会额外推进现实的房租、工作与人物日程。

在**游戏日志**查看梦中日期、当前线索和三种感受：

| 感受 | 影响                                         |
| ---- | -------------------------------------------- |
| 疑心 | 辨认矛盾、核对讲述，也可能让求助更难说出口   |
| 不安 | 稳住呼吸、等待、靠近危险和完成细致动作       |
| 注意 | 隐蔽行动与经过危险区域时，被发现或靠近的可能 |

选项旁会显示耗时、检定与变化提示。原版「隐藏数值」设置会隐藏相应数值。**检定看点击前的状态**，并受先前准备、选择顺序和当前时刻影响。吃饭、喝水、整理安全位置可以缓解不安，喊人、争执和声响会引人注意。

### 三种梦境

首次进入先度过悉尼来访的下午。画画、花园和厨房活动会留下后续线索，**不必做完所有活动才能继续**。

悉尼离开后，从门口选择分支。**两种分支都完成后，第三个主结局入口才开放**，顺序不限。

| 门口选择                 | 怎样推进                                                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **跟着悉尼的声音去花园** | 留意游戏规则、敲击声的停顿和画里的门。雨天的纸牌与捉迷藏都做过后，继续听楼下动静，重复的下午中，换杯子位置、让悉尼决定规则后，再检查下楼的路。 |
| **靠近厨房里的谈话声**   | 先偷听，再追问来客与父母的变化。晚饭前至少完成热食物、洗杯子或拿碗中的一项。                                                                   |
| **留下来听自己的声音**   | 从碎玻璃的夜晚继续，找食物、照料父母、清出退路并向外求助。先吃饭、喝水、腾出一只手或整理休息位置，会提供更稳妥的后续动作。                     |

厨房分支有两项时间窗口：**16:00–17:00 趁谈话洗杯子，17:00–17:30 隔着连通门偷听**。均包含开始时刻，不包含结束时刻。移动和准备也耗时，过时后仍有其他行动继续。

每种梦境的最后都有承诺与拒绝的分歧。约定会留到下一次梦里，厨房的保密约定尤其影响主线求助和留言。你可以遵守，也可以违约求助，违约会惊动屋里的东西。最初就拒绝保密，不会被记作违约。

游戏与检查不能无限重复。失手后仍有解释、退避或准备的办法，成功与失手都能推进到分支结尾。

### 醒来、继续与重玩

- **尚未到结局**：选「暂时醒来」。再闭眼回到中断的位置，保留本轮感受与选择。
- **已经到结局**：选「睁开眼睛」。再进入会回到分支门口，不必重做共有下午。
- **重玩已完成路线**：保留共有下午的经历、其他路线的约定与结局记录，本轮感受和普通活动重置。新的最终选择会替换这条路线原来的约定。
- **梦中保存**：可以读档继续。停用模块后读取梦中存档，会先恢复现实状态，并保留已记录的进度。

### 奖励与凯拉尔的后续

完成两种分支、主结局并**睁开眼睛**后，获得成就「**迷途羔羊**」和特质「**梦痕**」。成就沿用原版作弊、调试与游戏模式限制。

**梦痕使睡眠中因噩梦持续增加的压力减少 25%。**适用于普通睡眠及荒原绑架后的睡眠，不减少可操作噩梦里的战斗或剧情压力。重玩不叠加，停用模块后效果停止。

主结局后，**18:00 起**，在房间且能够正常活动的凯拉尔会出现「**和凯拉尔谈谈那个梦**」。三个话题只能选一个：

| 话题         | 耗时与结果                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 陪坐         | 十分钟，增加爱意、减轻嫉妒与 PC 压力。主线交出名字后，改为答应不会让别人带走你，安抚效果更明显。       |
| 问起那个夜晚 | 十分钟，增加爱意、减轻 PC 压力，仍守着厨房保密约定时，改为重复来客的保证，会损害爱意、增加嫉妒与压力。 |
| 独处         | 五分钟，减轻 PC 压力，凯拉尔嫉妒较高时，会进一步怀疑你想离开。                                         |

这次现实交谈只结算一次，重玩不会重置，也不会改写已经说出口的话。尚未选择话题时可以先离开，之后再谈。日后的房间描述随话题、爱意与嫉妒变化。
