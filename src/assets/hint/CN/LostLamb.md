# 迷途羔羊（Lost Lamb）· 庄园回忆指南

在凯拉尔的房间休息时，你可能梦见庄园的过去。你将在梦中作为年幼的凯拉尔行动，寻找那晚留下的记忆。

---

### 前置条件与开启方式

开启回忆梦境需满足以下前置：

1. **庄园线索**：在原版凯拉尔庄园中探索并发现了**圣体匣**。
2. **往事交谈**：与凯拉尔交谈过其父母的事，听过关于剧变之夜的断续回忆。
3. **庄园留宿**：已触发过原版首次在庄园过夜的事件。
4. **入梦入口**：凯拉尔处于正常活动状态且无特殊事件打断时，前往**凯拉尔的庄园 → 凯拉尔房间**，选择「**躺下休息一会儿**」，随后选择「**闭上眼睛 (0:30)**」即可入梦。

入梦耗时现实时间 30 分钟。梦境中的经历属于回忆演绎，随时可选择「暂时醒来」返回现实。身上的衣物、随身物品、金钱与现实日程均不受梦中流转影响。

---

### 梦境机制：三项心智指标

梦中的选择受三种感受影响，选项与结果会提示它们的变化。日志记录梦中的日期和当前线索。

| 指标     | 影响与机制                                                 | 应对与调控                                 |
| -------- | ---------------------------------------------------------- | ------------------------------------------ |
| **疑心** | 影响辨识矛盾与核对细节的能力，过高时可能难以启齿向外求助。 | 留意不同人对话中的细微差异。               |
| **不安** | 影响呼吸节奏与完成精细动作的稳定性，过高时容易慌乱出错。   | 进食、饮水或整理一处安全位置可缓解不安。   |
| **注意** | 衡量周围环境对你的警觉程度，过高容易引起注意。             | 避免大声喊叫或剧烈推拉门窗，行动尽量放轻。 |

---

### 流程阶段与分支解锁

初次入梦将从一个晴朗的来访下午开始。进行日常活动即可逐步推进：

1. **分支一（花园路线）**：下午结束后，在门口选择跟随门外的声音前往后门与花园。
2. **分支二（厨房路线）**：下午结束后，在门口选择靠近厨房的谈话声。
3. **主结局（最终门扉）**：**必须先分别完整探索过分支一与分支二**，第三个入口方会开放。
4. **中途退出与重试**：
   - 未达结局前可随时选「暂时醒来」，下次入梦会保留当前进度继续。
   - 达成结局后可选择「睁开眼睛」彻底苏醒。

---

### 奖励与现实后续

- **特质奖励**：完整通关后获得永久特质【**梦痕**】（睡眠中因噩梦导致的持续压力增加降低 25%）与对应成就。
- **现实对话**：通关后，在晚间（18:00 起）前往庄园卧室，凯拉尔在场且有空时，可选择「**和凯拉尔谈谈那个梦**」。选择陪伴、谈论那晚或留出一点空间，会影响这次交谈与之后的房间描述。话题成功讲完后才会登记。期间若被突发事件打断，可以等凯拉尔有空时再谈。读档、重绘或重新入梦不会重复获得已完成交谈的收益。
- **现实回响**：以下三段交谈分别完成，不要求先选定凯拉尔的话题，也不会自动改变恋爱对象：
  - 悉尼在学校图书馆、成人商店或神殿祈祷时有空，可选择「**轻叩桌上的暗号**」。如果你们已经在原版中一起送凯拉尔回庄园，交谈会承接这次见面。
  - 格威岚在森林商店营业时，可选择「**向格威岚打听旧事**」。是否已经向格威岚谈过凯拉尔的父母，会影响回应。
  - 已在原版中向主教问清庄园往事后，可在告解室相关交谈或神殿事务中选择「**询问封死的宅邸**」。

这些后续让你核对记忆与现实人物的说法。梦里的情景不会自动成为事实证据，也不承诺治好凯拉尔的父母或促成悉尼与凯拉尔重归旧好。
