### 前置条件与解锁顺序

「迷途羔羊」延续凯拉尔庄园的原版圣体匣见闻，提供事后的交谈与整理书桌。无需先开启罗宾神殿路线或加入唱诗班。

1. 启用**迷途羔羊**模块。
2. 按原版路线取得拜访庄园的资格，帮助清理庄园，取得凯拉尔父母充分信任。
3. 在庄园与凯拉尔交谈，选择原版汇报庄园已经清理干净的入口，跟随查看楼上的秘密。
4. **走完见闻，回到凯拉尔卧室。**仅开始调查或看到圣体匣还不够，模块在原版最后一页记录这次经历。
5. 之后在 **凯拉尔庄园 → 卧室 → 与凯拉尔交谈**，每天 **18:00–23:00** 寻找「问起圣体匣」。凯拉尔须能正常活动，PC 不在战斗中。

<span class="teal">如果凯拉尔此时正要赠送相机，先打开或拒绝原版礼物，再返回普通交谈。</span>新话题不会绕过礼物剧情。

### 怎样交谈，不同见闻有什么选项

| 选择                       | 额外前置                                     | 对话方向                                         |
| -------------------------- | -------------------------------------------- | ------------------------------------------------ |
| 听凯拉尔说                 | 已完成庄园见闻                               | 听取疑虑，以及你是否还会来探望的担忧             |
| 表示想先弄清楚，再作决定   | 已完成庄园见闻                               | 留下继续询问的余地，不替父母的遭遇作定论         |
| 坦白你已经问过约旦         | 已向约旦报告圣体匣，尚未听过主教的完整说法   | 凯拉尔得知神殿已经知道庄园的事                   |
| 告诉凯拉尔主教对庄园的说法 | 本局已听完主教揭密，对应原版「异教仪式」见闻 | 转述主教的解释，凯拉尔会面对父母遭遇与神殿的关系 |
| 坚持让神殿调查             | 已完成庄园见闻                               | 凯拉尔拒绝让神殿介入，结束这个话题               |

报告约旦的入口在 **神殿 → 与约旦交谈 → 询问庄园里的圣体匣**。主教的完整说法需要继续推进原版后续遭遇，报告本身不会直接解锁最后一种见闻。已听过主教揭密时，「告诉主教的说法」替代「坦白问过约旦」。

PC 的神殿身份，以及凯拉尔当前的嫉妒，会改变部分反应。**这段交谈记录你的立场，目前不会直接增减爱意、嫉妒或信仰，也不会使凯拉尔加入神殿、解决父母的遭遇。**

可以之后再问，重新选择立场。坚持调查不是永久封锁整条路线，但这次交谈后不会提供整理书桌。

### 整理书桌：在哪里，有什么效果

完成一次交谈，且最近选择不是「坚持让神殿调查」时，回到普通交谈页选择「留下来一起整理书桌 (0:15)」。每局可完成一次。

你们一起清理键盘旁的地方，整理凯拉尔留下的纸张。以后交谈页会提到保留下来的空位。这个行动提供后续相处文本，不发放金钱，不额外解锁成就，也不替你调查电脑或父母的秘密。

### 与其他路线的关系

- **混乱誓约**也读取本局的原版「异教仪式」见闻，但不要求完成本章交谈或整理书桌。知道主教的说法，不等于已经满足两位恋人的仪式条件。
- 不要求安装枯木逢春的凯拉尔拓展。其他模组带来的失踪、拘禁或无法活动状态，仍会影响是否能正常拜访。
- 本章在模块启用时记录原版最后一页的见闻。此前已经走完的经历不会被自动补记，也不从跨存档成就推定进度。

### 常见问题

| 问题                 | 怎么处理                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| 没有「问起圣体匣」   | 检查模块是否启用，是否在启用期间走完庄园见闻，是否在 18:00–23:00 的庄园卧室交谈页，凯拉尔是否能正常活动 |
| 礼物剧情占用了交谈页 | 先处理相机礼物，再返回普通交谈                                                                          |
| 没有约旦或主教的选项 | 前者需向约旦报告，后者需听完本局原版主教揭密，两种见闻不能互相替代                                      |
| 没有整理书桌         | 先完成交谈，最近立场不能是坚持神殿调查，且此前未整理过                                                  |
| 交谈后好感没有变化   | 当前行动记录对话立场与书桌状态，没有直接的属性奖励                                                      |
