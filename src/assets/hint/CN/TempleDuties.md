### 入口与推荐顺序

启用「神殿职务」，PC 是**见习教徒、修士／修女或司祭**，衣着完整、压力未满，约旦已登场且没有缺席时，在**神殿大厅**选择「**查看神殿职务簿**」。查看职务簿、资料室与神殿储藏室菜单、返回大厅或职务桌都不耗时；调查、工作、阅读与码头实地往返仍按选项扣时。

职务桌在 **09:00–18:00** 的白天开放，黄昏、夜间和周日 **11:00–13:00** 弥撒期间暂停。战斗、附身、待处理的强制剧情、临产与重放场景中无法办理。

先「**向约旦申请职务 (0:10)**」，再接班、查阅资料或领取调查。推荐顺序：**申请职务 → 阅读资料、完成调查 → 处理原版营救与取矛任务 → 门前守望 → 任职面谈 → 接受司祭任命**。主教的私下委托可以另行选择。

### 日常职务

每天只能完成**一班有薪工作**。普通职务最迟 17:00 接班，按选项为工作留足时间：

| 工作                   | 耗时    | 报酬与练习                                                 |
| ---------------------- | ------- | ---------------------------------------------------------- |
| 清点碗并核对收据       | 45 分钟 | £25、数学、恩典 +1、少量善行名声                           |
| 晾开毯子，留下交接记录 | 60 分钟 | £30、家务、恩典 +2、少量善行名声；增加疲劳                 |
| 指导下一班值班         | 45 分钟 | 司祭开放，£40、恩典 +2、少量善行名声                       |
| 巡查花园，修补护符     | 60 分钟 | 司祭开放，£40、护理、家务、恩典 +2；增加疲劳               |
| 与罗宾交接毯子         | 30 分钟 | 两人都是司祭，£30、家务、恩典 +1、罗宾信仰与爱意；减少压力 |
| 与悉尼核对资料室收据   | 30 分钟 | 两人都是司祭，£35、历史、数学、恩典 +1、悉尼爱意；减少压力 |

**以上工作与有薪案件回访共用每天一班的次数**。唱诗与原有共同值班保留各自次数。忏悔室、祈祷室与施粥所的原有职责仍可进行。花园工作按护理技能改善原有花园状态 **3–9 点，上限 100**。

罗宾或悉尼实际在神殿且有空时，可以谈谈职务，每天一次；已任职的同伴还可一起交接或核对收据，须能在下一项日程前完成半小时工作。**暖室休息每天一次、30 分钟**，减轻疼痛、疲劳与压力。PC 已是司祭，或当天刚结束守望／交回调查报告时，可在职务桌或收尾页面选择包扎休息。

### 旧资料室与修缮

申请职务后，从职务桌进入**旧资料室**，阅读建筑图纸、旧交货记录与外勤注意事项。首次阅读每种资料提升历史，并为调查提供线索。

| 准备           | 费用或耗时                       | 效果                                     |
| -------------- | -------------------------------- | ---------------------------------------- |
| 查阅资料       | 每次 30 分钟                     | 取得对应线索                             |
| 屋顶与排水     | £4,000，两天竣工                 | 与新书架共同改善查阅条件；增加善行名声   |
| 书架与防潮储存 | £1,500，一天竣工                 | 与屋顶工程共同改善查阅条件；增加善行名声 |
| 晾干并整理散页 | 每天一次，每次 30 分钟，最多三次 | 历史、家务、恩典；三次后查阅再省五分钟   |

**两项工程都竣工**后，查阅缩短至二十分钟；三次整理也完成时缩短至十五分钟。

全部修缮和三次整理完成后，修士／修女或司祭可「**抄录修复后的护符图样**」。抄录后，比对调查标记只需十分钟，外勤战斗少一条触手，门前守望第一场少两条根须，并进一步减轻两次撑住门槛的疼痛与疲劳。外勤注意事项能把撤离缩短至三分钟；旧交货记录也能帮助更快比对货箱标记。

修缮单独开收据，不使用已经安排买食物和毯子的基金。启用枯木逢春金融模块时，可用现金及已有的银行付款渠道，收据标明用途；没有相应模块时，以现金支付。

### 调查委托

依次领取三项委托。后两项留给已通过苦难审判的修士／修女或司祭。

| 委托             | 关键步骤                                                       |
| ---------------- | -------------------------------------------------------------- |
| **熄灯后的敲击** | 检查排水管与百叶窗，核实敲击来源。科学帮助检查扣件。           |
| **卷宗下的根须** | 标出出口、比对标记，再守住出口，与根须战斗。                   |
| **退回的捐赠箱** | 前往码头，找到受困工人、安排出口、核对标记，再与苍白触手战斗。 |

可在职务桌借用**灯、绳索与手套**。建筑图纸或诡术帮助规划出口；历史或格威岚的建议帮助比对标记；体能或借来的装备帮助救援。借来的装备缩短扣件检查、路线准备与救援所需时间，减轻救援疲劳；同时准备装备与出口，也能减轻战斗负担。

完成后返回职务桌「**向约旦汇报**」。如实解决三项委托，分别获得 **£60、£150、£200**，每项另有 **3 点恩典与善行名声**。每项报酬只领取一次；夸大报告会损害约旦对你的爱意。

未解决的案件可以重新安排。**三案均已如实解决、PC 已是司祭**后，每个案件间隔一周可安排有薪回访。现场可能已经安静、被水浸湿或移动了堆放物，需要重新检查；安静现场可以核实后直接结束检查。三案回访劳务费分别为 **£35、£60、£80**，另加恩典 1，不重复首次奖励。当天已经做过有薪职务时，报告保留到次日再结算。

正在调查时先处理案件，才能开始门前守望；进行守望时也不能同时接新案件。

### 司祭任命

PC 已是修士或修女，并满足以下条件后，可以准备任命：

- 完成**多瑙河街宅邸的营救**，把失踪的神殿成员带回来。
- **将金色长矛交还约旦**。仅结束取矛任务、遗失或丢弃长矛都不足。
- 已申请职务，神殿誓言完整，没有失败的待处理检查，检查期限尚未到。
- 通过**下层门前的守望**。

通过后，在职务桌选择任职审查，**17:00 前**「**向约旦讲述经过 (0:20)**」。约旦询问你怎样回应见习教徒的求助。愿意听取并同行核实时，可以继续考虑誓言；要求对方独自服从时，面谈暂缓，可以再来。

最后在暖室「**回答约旦，接受任命 (0:20)**」，成为司祭，增加约旦爱意与善行名声。也可先把同伴的准备做完，再共同接受任命。任职后开放指导、护符巡查与案件回访，**贞洁誓言和月度检查仍适用**。

### 门前守望

在职务桌「**询问下层门前的守望**」。**14:00 前**开始，每天一次，预留三小时；周日须等弥撒结束。先处理当前调查，并完成营救、交矛与誓言前置。

1. 选择同行者，或独自进入下层通道。
2. 阅读护符、检查归路并护住灯火，完成第一场根须战斗。
3. 守住应答，辨认门后的声音。
4. 完成第二场苍白触手战斗，再核对护符图样、清点人数并封门。

两场均使用原版战斗操作。属性与技能会帮助准备和承受环境负担：

| 条件                                 | 帮助                                           |
| ------------------------------------ | ---------------------------------------------- |
| 有效历史／科学 ≥400，或有效诡术 ≥500 | 找到归路，减少第一场根须数量                   |
| 有效体能 ≥5,000，或有效运动能力 ≥600 | 两次门槛前的疼痛、疲劳损耗减半                 |
| 有效歌唱／英语 ≥600                  | 应答的意志要求从 650 降至 550，疲劳从 8 降至 5 |
| 意识 ≥600                            | 应答的自控要求从 400 降至 350                  |

应答需要达到当前**有效意志与自控**要求，仍增加压力。高诡术或高意识有助于发现镜面异常。沿用抄录的护符图样，数清同行者；回答门外的声音、采用镜中图样、中途退出或超时，都无法通过。

**通过后仍保留疼痛与疲劳。**回暖室包扎、清点，再由约旦确认任职。失败后先返回安全处，下一天可重试。

通过门前守望会获得**守望者**：对非人生物的主动攻击与放逐伤害提高 **20%**。枯木逢春的武器与清除也衔接此加成。任职后，司祭身份可让守门人开放祈祷室。

### 陪同悉尼与罗宾

在职务桌选择「**与罗宾或悉尼商谈司祭任职准备**」。PC 为修士／修女或司祭时可陪同，每人需要：

- 已通过苦难审判，成为修士或修女。
- 本人同意，当前在神殿且有空，神殿誓言完整。
- 悉尼没有待执行的神殿惩罚。
- 罗宾已经处理待办检查与净化，**信仰至少 20、创伤低于 60**。

先分别陪同「**一起祈祷，听教徒诉说 (0:30)**」及「**陪资深司祭检查护符 (0:30)**」，再共同参加门前守望。

**PC 必须分别协助每位同行者护灯和应答，单靠自己战斗获胜不能替同伴取得资格。**同伴通过后，陪去见约旦面谈十五分钟，最后在暖室共同接受任命二十五分钟。可带一人或两人，PC 已成为司祭后仍可继续帮另一人准备。

所有同行都须在既有日程前留足时间。上学、看店、受罚、房产外出和接送优先；任命不会取消这些安排。罗宾通过守望会留下少量创伤，任职后床铺仍可使用。

### 主教与圣体匣

这是可选支线，不是司祭任命的前置。

- **密封便条**：与主教建立联系后，在职务桌答应核对记录。读旧交货资料、如实解决货箱委托，再到资料室「比对封印与旧货箱收据」。将副本交给等候的告解员，完成后提升历史。
- **圣体匣记录**：成为司祭、听完主教对凯拉尔庄园的揭密后，在职务桌询问庄园与新职务。接受后读资料室索引，再到庄园问凯拉尔。入口在 **18:00–23:00**，凯拉尔须能够活动、嫉妒低于 30，PC 没有被跟踪或控制。

凯拉尔决定哪些可以记下。交出同意分享的记录后完成调查，获得 **£60 与历史 +2**；也可拒绝或将谈话留在你们之间。这条线不会治愈其父母。完成或拒绝后，任务提醒从日志隐藏。

### 找不到入口时

- **职务簿不见了**：核对模块、神殿身份、衣着、压力、约旦与白天接待时段，先处理大厅剧情。
- **调查没有报酬**：须真正解决并如实汇报，首次报酬只领一次；有薪回访还需三案全部完成、司祭身份、满一周且当天有薪次数未使用。
- **不能开始守望**：核对交矛、营救、誓言、当前调查、当天次数，以及自己和同伴的空闲时间。
- **同伴不能面谈**：两项练习及本人守望均须完成，护灯和应答不能漏掉。
- **不能问圣体匣**：须先接受支线，在晚间找到状态合适的凯拉尔；只见过庄园秘密还不足。
