# 神殿职务与司祭任命

参加轮值、修缮资料室，随修士外出处理异状。熟悉后可以负责带队，罗宾与悉尼也能见习、出勤，准备任职。

### 从哪里开始

成为见习教徒后，将楼上宿舍打扫至**整洁度 100**，侍从会提到约旦需要帮手。司祭可以直接申请。

衣着得体，在**白天 09:00–18:00**到大厅「**查看神殿职务簿**」，避开周日 **11:00–13:00**的弥撒。申请后先完成一次交接，再接取外出委托。

### 外出委托

四项委托依次开放，后三项需要修士或司祭身份。完成后向约旦如实汇报，才能接到下一项。失败或撤退后可以重试。

| 委托         | 去哪里、做什么                                         | 首次报酬 |
| ------------ | ------------------------------------------------------ | -------- |
| 熄灯后的敲击 | 从职务桌进入储藏室，检查排水管与百叶窗                 | £60      |
| 卷宗下的根须 | 在码头旧仓房与修士会合，留好退路、击退根须并取回交货簿 | £150     |
| 退回的捐赠箱 | 到码头仓库救出工人，击退触手、带回记录                 | £200     |
| 湖岸外的祷声 | 从湖岸循声入林，救出受困者，再追查林中据点             | £200     |

每项首次如实完成，还得**恩典 +3、善行名声 +10**。完成仓库或湖岸委托并如实汇报后，获得「**驱邪之术**」：主动攻击与放逐对非人生物的伤害提高 **20%**。

启用触手时，旧仓房与仓库会进入触手战。修士会协助第一次调查，之后由你负责。提前勘查、准备装备能减轻负担。关闭触手时，完成救援、核对标记后，花 **5 分钟**封好入口、带走记录。

### 湖岸调查

接到委托后，在**白天 09:00–16:00**前往湖岸，花 **10 分钟**进入树林。

- 先观察，留好退路。可以回去告诉约旦，请资深修士到湖岸接应。
- **诡术 400**可以潜入松开绳结，再找机会带走受困者。直接上前会与拦路者战斗，观察人群或带来帮手能减少对手。喝令让开则需要体能与意志。
- 救人后先回报，再追查林中据点。救出那里的人、取回记录、处理危险后，向约旦结案。
- 中途离开会保留已救出的人和完成的调查。再次出发前，可以重新邀请同伴。

| 准备                         | 帮助                       |
| ---------------------------- | -------------------------- |
| 运动或外勤记录               | 更快标记退路与撤离         |
| 历史、格威岚的建议或护符图样 | 找出可破坏的线条，减少触手 |
| 科学与借来的器具             | 用湿土闷熄香炉，削弱触手   |
| 体能或借来的器具             | 减少护送受困者的疲劳       |
| 意志                         | 减轻惊吓、理智损耗与恐惧   |

成为司祭、前三项委托如实完成后，每隔**七天**可回访这三处。报酬依次为 **£35／£60／£80**，另得恩典 +1，占用当天有薪工作。现场发生变化时，仍可能遭遇触手。

### 司祭任命

登记职务、成为修士，依次完成旧仓房、仓库及湖岸调查并如实汇报后，还需：

- 从多瑙河街宅邸救回失踪教徒。
- 将金色长矛交回约旦。
- 保持神殿誓言，通过当前月度检查。
- 任命时，恩典须达到100。

在 **17:00 前**找约旦谈任命。面谈后接受约**六小时**的授职考验，可以中途休息、改日继续。以下五项都须完成，可以与一同受试的罗宾、悉尼配合：

| 考验     | 所需能力                               |
| -------- | -------------------------------------- |
| 领诵     | 语文或历史400，或已加入唱诗班且歌唱300 |
| 抵御低语 | 意志500                                |
| 承持香炉 | 体能5,000                              |
| 接续祷文 | 历史400或意志500                       |
| 陈述调查 | 历史或语文400                          |

抵御低语、承持香炉也可以与同伴共同完成，请侍从搭把手。领诵、接续祷文与陈述调查需要相应的能力。未完成全部考验时，先练习，再重新尝试。调查与轮值资历保留。

通过后宣誓，获得好感、名声与精神恢复，并可使用司祭职务、进入祈祷室。之后仍需参加月度检查。

### 罗宾与悉尼

先在各自的神殿长椅谈任职。对方需成为修士、守持誓言，并处理好检查与净化。罗宾还需**信仰至少 20、创伤低于 60**。

1. 在候任名册安排接待教徒、巡查护符两次见习，各 **30 分钟**。
2. 接下仓库或湖岸委托后，在出发前邀请同伴到现场会合，留出 **90 分钟**空闲。
   湖岸调查遇到拦路者时，同行的罗宾与悉尼会留意你的侧后方，帮你挡开伸来的手。罗宾的自信与创伤会影响掩护效果。
3. 同伴亲自救人、取证或拆除危险布置后，记下任职经历。完成委托，再如实汇报。湖岸调查结束后，也可陪缺少经历的同伴回去护送证人、核对记录。
4. 陪同面谈 **15 分钟**，再准备**六至七小时**的授职考验，可以中途停下再继续。与罗宾同行时，适合在**假期平日 09:00**开始。

任命后，罗宾保有神殿床铺，悉尼可以进入祈祷室。

### 资料室

申请职务后，可以阅读建筑图、交货记录与外勤记录。首次阅读提升历史。

| 项目           | 花费                  | 用途                             |
| -------------- | --------------------- | -------------------------------- |
| 查阅卷宗       | 30 分钟               | 获取线索                         |
| 修缮屋顶与排水 | £4,000，2 天          | 与新书架共同改善阅读条件         |
| 更换防潮书架   | £1,500，1 天          | 与屋顶修缮共同改善阅读条件       |
| 晾干、整理散页 | 每天 30 分钟，共 3 次 | 历史、家务与恩典，进一步缩短阅读 |

两项工程完工后，阅读缩短为 **20 分钟**。散页也整理完后为 **15 分钟**，修士与司祭还能抄录护符图样。图样使现场比对缩短至 **10 分钟**，减少一条触手。外勤记录使撤离缩短至 **3 分钟**。

出发前可向约旦借灯、绳索与手套。

### 日常工作

每天一班有薪工作，最晚 **17:00**开始，避开弥撒。接待求助教徒需在 **17:00 前**开始。回访也占用当天这一班。

| 工作                         | 耗时    | 主要收获                                     |
| ---------------------------- | ------- | -------------------------------------------- |
| 清点圣碗、核对收据           | 45 分钟 | £25、数学、恩典 +1与善行名声                 |
| 晾晒毯子、交接登记           | 60 分钟 | £30、家务、恩典 +2与善行名声                 |
| 指导下一班（司祭）           | 45 分钟 | £40、恩典 +2与善行名声                       |
| 巡查花园、修补护符（司祭）   | 60 分钟 | £40、护理、家务、恩典 +2，改善花园 3–9 点    |
| 与罗宾交接毯子（双方为司祭） | 30 分钟 | £30、家务、恩典 +1、罗宾信仰与好感，缓解压力 |
| 与悉尼核对收据（双方为司祭） | 30 分钟 | £35、历史、数学、恩典 +1、悉尼好感，缓解压力 |
| 接待求助教徒（司祭）         | 30 分钟 | £40、恩典 +2，按应对练习语文或历史           |

接待每天有不同来访者，你的意志、语文与历史影响应对的负担。之后可以在长椅上与罗宾、悉尼谈起，听他们的看法。

疲惫或受伤时，可每天在桌旁暖室休息 **30 分钟**，减轻疼痛、疲劳与压力。

### 私下委托

- 与主教建立联系后，可以接下职务桌的密封便条。查阅交货记录，办完货箱委托并如实汇报，再另抄比对记录，交给以告解员身份等候的主教。
- 成为司祭、听过庄园往事后，可以接下圣体匣记录。先查索引，再在 **18:00–23:00**拜访有空的凯拉尔。需要**嫉妒低于 30**，没有跟踪或控制。只记下对方同意分享的内容，可以交回领取 **£60、历史 +2**，也可以保密。完成迷途羔羊后，交谈会提起梦里的记忆。
