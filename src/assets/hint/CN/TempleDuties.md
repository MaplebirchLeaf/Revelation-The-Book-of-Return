# 神殿职务与司祭任命

申请职务后，你可以参加轮值、修缮旧资料室，再随修士外出处理异状。熟悉之后，约旦会让你独立负责仓库救援，再调查湖岸外的祷声。罗宾和悉尼也能先见习，再与你一起出勤、准备任职。

### 从哪里开始

- 成为见习教徒后，先将楼上的宿舍打扫至整洁度 **100**。侍从会提到约旦需要帮手。取得资格后，宿舍再次变脏不会关闭入口。司祭可以直接申请。
- 在 **09:00–18:00**、天色未暗时，从神殿大厅「查看神殿职务簿」，向约旦申请职务。避开周日 **11:00–13:00** 的弥撒。衣着需得体，且没有战斗、附身或优先事件。
- 翻看职务簿、资料室菜单和往返大厅不耗时。工作、阅读、调查和实际走动按链接标明的时间结算。

推荐路线：**申请职务 → 完成首次交接 → 调查敲击声 → 随修士处理旧仓房 → 独立负责仓库救援 → 湖岸外的祷声 → 约旦面谈 → 司祭任命**。营救失踪教徒、归还金色长矛也需要完成，不必按固定顺序。

### 从随行到独立抵御

四个委托依次开放。后三项限修士或司祭接取，前一项需妥善处理并如实汇报。失败、退出或夸大报告后，可以重新调查。

| 委托         | 去向与任务                                                     | 首次如实完成报酬 |
| ------------ | -------------------------------------------------------------- | ---------------- |
| 熄灯后的敲击 | 从职务桌前往神殿储藏室，检查排水管与百叶窗                     | £60              |
| 卷宗下的根须 | 前往码头旁的旧仓房，与修士会合。留好退路，击退根须并取回交货簿 | £150             |
| 退回的捐赠箱 | 前往码头仓库。接出工人，击退紫色触手，带回记录                 | £200             |
| 湖岸外的祷声 | 从湖岸循祷声入林。接出受困者，再循线索处理林中据点             | £200             |

- **启用触手时，旧仓房与仓库都有原版触手战**。第一次修士会协助压制根须，之后的仓库由你负责。先勘查、准备装备会减少战斗压力。也可以冒险直接迎战。关闭触手时，先标记退路、核对标记，仓库还需救出工人，再花 **5 分钟**封好入口、带走记录。撤离后可以重新接取，不能谎报成完成。
- 每项首次如实完成另得 **恩典 +3、善行名声 +10**。如实完成独立抵御后，获得「**驱邪之术**」：对非人生物的主动攻击与放逐伤害提高 **20%**。已有的任职与试炼收益保留。
- 仓库救援如实汇报后，可以接取「湖岸外的祷声」。在 **09:00 后、16:00 前的白天**到**湖岸**，从正常菜单花 **10 分钟**进入树林。入场后可以继续处理。观察需 **5 分钟**，标记退路通常需 **5 分钟**。观察后也可先向约旦汇报，资深修士会在湖岸接应，协助压制触手。这次汇报不算完成救援。观察并留好退路后，**诡术 400** 可花 **5 分钟**潜入，先松开绳结。趁转身空隙实际带开受困者后，才记录救援。直接上前会进入原版人类 Combat。观察过人群或带来接应，可以减少拦路者。也可尝试喝令让开，体能或意志任一不足时会转入战斗。摆脱拦路者后仍需实际解缚、护送，不能直接结案。
- 湖岸的救援与触手处置只是调查的一段。先回去向约旦说明，再循新线索查找林中据点。接出里面的人、带回记录并处理剩余危险后，才可如实结案。关闭触手时保留救援与取证。中途撤离后，获救者仍有人照料，已完成的处置保留。再次出发前可重新安排同伴，不会重演受困者被绑的仪式。
- 成为司祭、前三项委托均已如实完成后，这三处每隔 **七天**可回访。报酬依次为 **£35／£60／£80**，另得恩典 +1。安静的回访只需核查，不必战斗。潮湿或布置改变的现场仍可能有触手。今天已领取值班报酬时，可隔日再交报告。「湖岸外的祷声」只发放首次完成报酬，没有每周回访。

湖岸调查中的准备会实际影响处置：

| 准备                       | 用途                                           |
| -------------------------- | ---------------------------------------------- |
| 运动技能                   | 更快标记退路与撤离。读过外勤记录也能缩短撤离   |
| 历史、格威岚建议或护符图样 | 观察后比对线条，找出可破坏的位置，减少触手数量 |
| 科学与借来的器具           | 准备湿土闷熄香炉，降低触手生命值               |
| 体能或借来的器具           | 减轻带开受困者时的疲劳                         |
| 意志                       | 缓和观察与打断仪式造成的惊吓、理智损耗与恐惧   |

### 约旦的面谈与任命

新申请任命的修士需已登记职务，依次完成旧仓房、仓库及「湖岸外的祷声」并如实汇报，且：

- 从多瑙河街宅邸救回失踪教徒。只听说失踪不够。
- 将金色长矛交回约旦。只找到长矛不够。
- 保持神殿誓言，并通过当前月度检查。

在 **17:00 前**找约旦谈司祭任命。面谈会谈起你实际做过的事，以及往后在神殿的职责。可以表达愿意帮忙，也可以说起仍在担心的事，或暂缓宣誓。任命在大厅祭坛前举行，保留好感、名声、恩典与精神恢复收益，并开放司祭职务和祈祷室通行。已任职的司祭保留职阶。原有仓库试炼记录继续有效。**月度检查照常继续**。

### 罗宾与悉尼

1. 在各自的神殿长椅谈任职，先听对方是否愿意。候选人需已成为修士、守持誓言且没有待处理的检查或净化。罗宾还需 **信仰至少 20、创伤低于 60**。
2. 在候任名册安排两次见习：接待求助教徒、随资深司祭巡查护符，各 **30 分钟**。
3. 接下仓库或湖岸委托后、前往现场前，在委托说明中邀请同伴到相应地点会合。须留出 **90 分钟**空闲，不跨越弥撒、上课、工作或已有出行。跨日后，同伴不会自动再次到场。
4. 任职经历按同伴实际完成的救助、取证或拆除危险布置记录，仅邀请或由你独自战斗不算。仓库中的协助各 **10 分钟**，林中据点也有各自的工作。完成后向约旦如实汇报。旧仓库试炼记录保留。湖岸调查办结后，尚缺经历的同伴可回去护送证人、核对记录。普通的安静巡查不计任职经历。
5. 陪同面谈 **15 分钟**，授职考验需预留 **六至七小时**，可中途停下再继续。与罗宾同行时，约在**假期工作日 09:00**开始。已任职后仍可带同伴补完外勤。

同伴仍按原有日程活动。任命收益只发放一次，罗宾保留神殿床铺，悉尼的职阶与神殿通行随任命更新。

### 资料室与准备

申请职务后，可以查阅建筑图、交货记录和外勤记录。首次阅读提升历史。已读内容可以重看。

| 项目           | 费用或耗时            | 用途                                       |
| -------------- | --------------------- | ------------------------------------------ |
| 查阅卷宗       | 每次 30 分钟          | 获取调查线索                               |
| 屋顶与排水修缮 | £4,000，工期 2 天     | 与新书架共同改善阅读条件                   |
| 更换防潮书架   | £1,500，工期 1 天     | 与屋顶修缮共同改善阅读条件                 |
| 晾干、整理散页 | 每天 30 分钟，共 3 次 | 历史、家务、恩典。完成后进一步缩短阅读时间 |

两项工程完工后，阅读缩短为 **20 分钟**。散页也整理完后缩短为 **15 分钟**，修士及司祭还能抄录修复后的护符图样。图样让现场比对缩短至十分钟，并减少一条触手。外勤记录让撤离缩短至三分钟。

出发前可向约旦借灯、绳索与手套。装备、建筑图和相关技能影响调查耗时、救援负担与战斗准备。启用触手时，准备不能代替战斗。

### 日常工作

每天可领取一班有薪工作的报酬，普通值班最晚 **17:00** 开始。司祭的回访检查也占用当天这一班。

| 工作                         | 耗时    | 报酬与主要收益                                   |
| ---------------------------- | ------- | ------------------------------------------------ |
| 清点圣碗与核对收据           | 45 分钟 | £25、数学、恩典 +1、善行名声                     |
| 晾晒毯子与交接登记           | 60 分钟 | £30、家务、恩典 +2、善行名声。增加少量疲劳       |
| 指导下一班轮值（司祭）       | 45 分钟 | £40、恩典 +2、善行名声                           |
| 巡查花园与修补护符（司祭）   | 60 分钟 | £40、护理、家务、恩典 +2。改善花园，增加少量疲劳 |
| 与罗宾交接毯子（双方为司祭） | 30 分钟 | £30、家务、恩典 +1、罗宾信仰与好感。缓解压力     |
| 与悉尼核对收据（双方为司祭） | 30 分钟 | £35、历史、数学、恩典 +1、悉尼好感。缓解压力     |

司祭可以在职务簿选择「接待前来求助的教徒」。每天轮换受惊的访客、练习答词的见习教徒，以及想弥补过错的来访者。每次接待 **30 分钟**，须在 **17:00 前**开始并避开弥撒，占用当天有薪职务，报酬 **£40、恩典 +2**。不同应对会运用意志、语文或历史，影响自身承受的压力，也会提升相应的语文或历史技能。最近接待的经历可在长椅的职务交谈中提起，罗宾与悉尼会按各自的态度回应。

花园维护按护理技能改善 **3–9 点**，上限 100。受伤或疲惫时，可以每天在职务桌旁的暖室休息 **30 分钟**，减轻疼痛、疲劳与压力。

与罗宾、悉尼谈职务的入口位于各自的神殿长椅，需本人在场且有空。已有的告解、祈祷室、施粥所和唱诗班保留各自的条件。

### 可选的私下委托

与主教建立联系后，职务桌可能出现密封便条。答应后，查阅旧交货记录，完成货箱调查并如实汇报，再到资料室另抄一份比对记录，交给以告解员身份等候的主教。可以拒绝，不影响司祭任命。

成为司祭并听过主教对凯拉尔庄园的说明后，可以接下圣体匣记录。先查阅索引，再在 **18:00–23:00** 拜访庄园中状态正常的凯拉尔。需要嫉妒低于 30，且没有跟踪或控制。只记录凯拉尔同意提供的内容，交回后得 **£60、历史 +2**，也可以选择保密。迷途羔羊会增加回忆差分，不是前置。
