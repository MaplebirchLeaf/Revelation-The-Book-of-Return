# 罗宾 · 神殿生活

邀请罗宾加入神殿，陪伴试炼、劳动与祈祷。你们也可以商谈承诺仪式，一起准备司祭任命。

### 邀请与纯洁试炼

你需已是见习教徒、修士或司祭，衣着得体、压力未满。罗宾需**好感至少 100、创伤低于 80**，身体状况良好。等罗宾在房间有空时，选择「**和罗宾谈谈神殿**」。同住后，也可以在自宅交谈。

1. 提议一起去问约旦。白天约旦有空时，陪同拜访，再约定**两天后**试炼。同行和预约共 **20 分钟**。
2. 预约后，可在 **17:00–19:15**从家里陪罗宾准备，每天一次、**45 分钟**。也可以送出正戴着的**十字架或石制吊坠**，帮助准备。
3. 到期后，在神殿宿舍参加试炼，或从家里陪同前往。**上学日 06:00–08:00，不上学时 06:00–18:00**，还需约旦在场。错过时间可以改日再来。
4. 保有初次贞洁时直接通过，否则接受火焰试炼。自信与准备会提高通过的机会。失败后先安慰罗宾，**七天后**可商量重试，再预约两天后的试炼。

入教后开放神殿里的交谈与更衣处。通过苦难审判后，罗宾会成为修士，获得自己的床铺。

不上学的平日 **09:00–15:45**，也能从家里邀请同行。罗宾上学、摆摊、工作、洗澡或已有约定时，等有空再来。住院、受伤或严重创伤也会暂缓活动。找不到罗宾时，可以在宿舍询问侍从。

同时使用枯木逢春时，家教在上学日周二、周四 **17:30–18:30**，六次后增加周五。饮品店晚班为 **18:30–21:00**，假期平日另有白天班，**09:00–16:00**优先完成神殿职责。

### 一起劳动与祈祷

每天可以一起做一次神殿工作：

| 活动     | 开始时间与耗时                                        | 主要收获                         |
| -------- | ----------------------------------------------------- | -------------------------------- |
| 照料花园 | 不上学的平日 09:00–10:00，1 小时                      | 花园状况、护理、信仰、好感与恩典 |
| 清扫宿舍 | 不上学的平日 13:00–15:00，1 小时                      | 整洁度、家务、信仰、好感与恩典   |
| 整理物资 | 平日 13:00–15:00，或约好的晚间同行中 19:00 前，1 小时 | 信仰、自信与恩典                 |
| 准备弥撒 | 周日 11:00–11:30，30 分钟                             | 信仰、好感与恩典                 |

请在表中时段结束前开始。花园和宿舍需罗宾正在那里工作。共同劳动会按你的护理或家务技能改善 **3–9 点**。

在大厅 **11:00–20:00**、弥撒以外的时间，可以靠近罗宾，在长椅交谈。每日一次的祈祷可以帮助他人、谈论疑惑、观察访客，或谈身体方面的不安。不同选择影响信仰、好感、自信、压力或意识，观察访客也可能增加创伤。

罗宾的**信仰与疑虑**影响态度。你的**恩典**、罗宾的**神殿贡献**和一起做工的次数则用于评估各自的付出。

### 礼物与散步

- 罗宾创伤低于 **40**时，可以送食物，每天一次、**5 分钟**。普通食物增加好感，太妃糖布丁更受欢迎。
- 每天可一起捐献一次，使用现金。捐 **£1／£5／£25**有不同收获，较高的捐献也会带来恩典。
- 每天可以散步一次，**30 分钟**，需在 **20:00 前**及罗宾下一项安排前结束。森林和电影邀约还需完成当天共同劳动，电影需 **£15**、足够感情和 **19:00 前**出发。
- 完全转化后，可以用尾巴、耳朵、翅膀或角与罗宾互动，每天共三次、每次 **10 分钟**。马、鲸鱼与渡鸦互动需要枯木逢春的更多转化。
- 压力达到上限的 **80%**、尚未崩溃时，可以每天在长椅休息半小时，罗宾可能陪你去医院。

### 苦难审判与床铺

从神殿的周日守夜参加苦难审判，关系亲近时可以牵住罗宾的手。一起通过后，罗宾成为修士，得到床铺、衣柜和镜子。

罗宾周六留宿时，恋人可以靠近、亲吻或一起睡下。承诺后，不上学的平日 **13:00–15:45**也可邀请在场的罗宾到床铺边。

神殿职务开放后，愿意任职的修士罗宾可以先见习，再参加仓库或湖岸委托，亲自帮忙后陪同面谈与任命。具体步骤见神殿职务指南。

### 忏悔

你听过**五次忏悔**后，在神殿的罗宾可能成为告解室访客，每天至多一次。话题会随关系、誓言、经历与信仰变化。

宽恕、悔改与赎罪的回应随话题不同。暴露身份后，罗宾会用三下敲门作暗号。邀请罗宾到你这一侧需要恋人关系，也可能被拒绝。创伤达到 **40**时，会改为一起离开。

### 承诺与月度检查

双方都入教、处于恋人关系，罗宾信仰不低于 **−20**，没有待完成的共同净化或另一份承诺时，可以白天在宿舍谈承诺仪式。

约旦会考察你们的付出、信仰、纯洁与相处。评估通过后，前往祭坛完成仪式。失败后需等 **30 天**再评估。

承诺让你们在誓言下亲密。之后约每 **30 天**接受共同检查。检查通过且获得津贴时，会一并领取唱诗报酬。拒绝检查、承认破誓或检查失败，会开始共同净化。

在宿舍 **11:00–20:00**、弥撒以外，可以商量取下罗宾的神殿贞操器具。承诺前需恋人关系、**自信 60**和**两次共同工作**，先谈 **15 分钟**，再白天陪罗宾去找约旦。尚未承诺且保有初次贞洁时，需 **£80 现金**。也可以商量重新戴上。

### 混乱誓约

想与罗宾和悉尼立下第二份承诺，需先了解三段往事：主教对凯拉尔父母的完整说明、狱卒与女巫同场的地下牢狱结局，以及湖底幻象。

还需满足：

- **淫乱 6**，与两人都是恋人，恰好已有其中一人的承诺。三人誓言完好，没有待完成的净化或贞操器具。
- 罗宾已入教，**好感至少 80、创伤 40 至 80 以下**。悉尼**好感至少 125**，处于堕落路线。先与罗宾承诺时，还需完成悉尼的堕落仪式。
- 先分别私谈，白天勘查湖底废墟，完成准备。从最后一次谈话或勘查起等**三天**。

在**血月 21:00–23:00**到湖边会合。湖面需未结冰、没有雨、围观或追猎。你的疼痛需低于 **50**、疲劳低于 **1,500**、压力距上限超过 **40**。

第一次同行先调查石头。之后再等三天，分别听取两人的决定并准备下一次同行，也可以尝试当晚的诡术说服。正式仪式需两人**性欲各至少 60**并分别同意。返回岸边确认后，增加一位承诺对象，今后参加三人的月度检查。

完成后可在白天相聚，比较听见的声音、相互掩护或一起撤离。长椅与床边交谈会提起这些经历。也完成迷途羔羊的主结局后，平日睡眠可能梦见两段往事交织的镜子。
