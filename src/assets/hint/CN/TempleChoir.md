### 前置条件与推荐顺序

唱诗班是约旦安排的神殿工作，新增「歌唱」技能。**不要求罗宾加入神殿，也不要求先解锁罗宾的承诺路线。**

- 启用「神殿唱诗班」模块。
- PC 已通过原版入殿试炼，身份为**见习教徒、修士／修女或司祭**，尚在申请阶段时不能加入。
- 衣着完整，约旦已经登场，能够进入神殿大厅的正常活动选项。正在发生的检查和剧情需要先处理。

推荐顺序：**大厅询问唱诗班 → 每日练习 → 周日随班唱诗 → 月检领取津贴 → 提高基础歌唱并争取领唱**。

### 如何加入，在哪里练习

在 **神殿 → 大厅**选择「询问唱诗班 (0:10)」，完成约旦安排的试唱即可入职。没有最低歌唱等级要求，初学者也会被接纳。较好的歌唱会改变约旦的评价。入职会练习歌唱并增加恩典。

之后仍在**神殿大厅**选择「参加唱诗练习」。每天 **09:00–18:00** 可练习一次，周日 **11:00–13:00** 弥撒期间暂停。先进入练习页，再选择一项练习，实际耗时三十分钟。

| 练习     | 效果                               | 适合什么时候选               |
| -------- | ---------------------------------- | ---------------------------- |
| 练习换气 | 提升歌唱、增加少量疲劳，减轻压力   | 想练习，同时需要缓解压力     |
| 练习音准 | 三种练习中歌唱进步最多，疲劳也较多 | 状态良好，想优先提高基础技能 |
| 排练合唱 | 提升歌唱、增加少量疲劳，增加恩典   | 同时积累神殿贡献与合唱经验   |

三项共用当天的练习次数。仅打开练习页不算完成练习，选定练习后才登记。**最近两天内完成过练习**会帮助周日唱诗发挥，很久以前的练习不再提供这项帮助。

### 神殿之外的练唱

启用唱诗班模块即可获得下列练唱收益，不要求已经入团或加入神殿。

- **酒吧艺人**：沿用原版完全哈比转化后的「跟着唱」选项，每次提高基础歌唱 10 点。打赏和只听音乐不会提升技能，艺人仍按原版每周出现条件提供互动。
- **鹰塔栖木**：沿用原版「唱歌 (0:30)」，每次提高基础歌唱 8 点。大鹰是否应和及其反应仍由原版日程、转化和关系决定；独自唱歌也能练习。
- **哈比加成**：转化等级达到 3 时，歌唱发挥提高 20%。这是当前发挥加成，不会直接增加基础技能或替代领唱资格。

练唱沿用技能上限和属性冻结规则，不计作唱诗班排练，也不产生神殿报酬。

### 歌唱等级与发挥

到 **角色 → 属性 → 技能**查看「歌唱」。等级沿用原版技能卡：**无、F、F+、D、D+、C、C+、B、B+、A、A+、S**，最高为 S。

日常练习、入职试唱和弥撒中的实际歌唱都会提高基础技能。启用罗宾神殿路线后，完全哈比转化的 PC 还可在神殿长椅为罗宾唱歌，额外练习歌唱。

| 当前状态                   | 对唱诗的影响                                 |
| -------------------------- | -------------------------------------------- |
| 哈比转化发展到技能加成阶段 | 改善当前歌唱发挥，不要求完全转化才能获得加成 |
| 疲劳较高                   | 降低发挥，先休息更稳妥                       |
| 醉酒                       | 降低发挥，与疲劳影响可以同时存在             |
| 最近两天练习过             | 帮助稳住每一节的表现                         |

技能卡会列出哈比、疲劳与醉酒的加成或减益。**基础技能**和**当场发挥**不同，领唱资格看基础等级，哈比加成不能代替把基础歌唱练到 B。

### 周日唱诗：入口与完整步骤

**周日 11:00–13:00**，从神殿大厅选择「随唱诗班参与弥撒 (1:00)」。每天只能参加一次，同日已经参加普通弥撒时不能再参加唱诗。

1. 依次唱**开场赞美诗、经文答唱、结束赞美诗**，每段二十分钟，共一小时。
2. 每一段都可选择「跟随合唱」或「支撑和声」，获得资格后还有「领唱这一节」。三段可以选择不同方式。
3. 留意段落反馈与当前表现分数。唱错仍可继续，唱诗班会接住你的声部。
4. 第三段结束后听约旦评价，让本次工作完成登记，再返回大厅。

| 方式       | 建议                             | 稳稳唱完的分数 |
| ---------- | -------------------------------- | -------------- |
| 跟随合唱   | 入门时优先选择，要求最低         | 2 分           |
| 支撑和声   | 对技巧要求更高，歌唱练熟后再尝试 | 2 分           |
| 领唱这一节 | 要先获约旦批准，也最考验当前发挥 | 3 分           |

任何方式勉强跟上均得一分，没跟上则不加分。技能、最近的练习与当前状态共同影响结果，较高等级也不是每节都成功的保证。每段增加疲劳，顺利或勉强跟上能缓解少量压力，没跟上会增加压力。

完整完成工作还会增加**纯洁与恩典**，表现较好时增加约旦的爱意。即使表现不佳，只要唱完三段，也会登记工作与保底加款。

<span class="red">开始唱诗就会占用当天弥撒机会。中途退出没有本次津贴加款，也不能当天重开。</span>此前累积的加款保留。

### 领唱怎样解锁

以下条件须同时满足，由约旦在**完整唱诗结束时**批准：

- 已完成至少**三次日常练习**。
- 已完整参加至少**三次唱诗**，中途退出不计入次数。
- **基础歌唱达到 B 级或以上**。
- 本次唱诗取得至少**五分**。

达到条件的第三次唱诗也能计入工作次数。批准后的**下一次唱诗**即可选择领唱，不需要重新申请。只把技能练到 B，未完成出勤与表现条件，不会出现领唱。

### 津贴怎么算，什么时候领取

完成一次唱诗，月度津贴增加 **£70**，每分表现另加 **£20**。

| 本次表现                   | 加入账册的金额 |
| -------------------------- | -------------- |
| 0 分，仍完整唱完           | £70            |
| 5 分                       | £170           |
| 6 分，跟唱或和声的最高表现 | £190           |
| 9 分，三段都成功领唱       | £250           |

混合方式按实际总分计算。这些金额是**等待领取的唱诗加款**，不会在每周日结束时立即发到钱包。

到期接受神殿月度检查，**通过并获发津贴时**，加款随原版津贴一并领取。原版津贴仍按恩典计算。若检查失败，或因恩典不足而被扣发津贴，加款会保留，直到之后获准领取。与罗宾或两位承诺对象一起接受检查时，也使用同一笔加款。

在**游戏日志 → 神殿唱诗班**查看尚未领取金额、完成练习与唱诗次数、领唱许可和时间安排。

### 常见问题

| 问题                   | 核对顺序                                                                   |
| ---------------------- | -------------------------------------------------------------------------- |
| 大厅没有询问唱诗班     | 模块是否启用、是否为适用神殿身份、衣着是否完整，当前原版剧情是否先占用大厅 |
| 没有练习选项           | 是否已入职、是否在 09:00–18:00、今天是否练习过、是否处于周日弥撒时段       |
| 周日没有唱诗入口       | 是否在 11:00–13:00、是否参加过当天普通弥撒或唱诗，是否仍符合成员与衣着条件 |
| 技能卡等级高却不能领唱 | 确认基础歌唱为 B 或以上，再检查三次练习、三次完整工作和本次五分表现        |
| 唱诗结束钱包没增加     | 去日志看加款，月检通过且津贴正常发放后再领取                               |
| 唱错后不知道怎么继续   | 继续剩余段落，低分仍有完整工作的保底加款                                   |
| 练习或工作没有技能增长 | 检查是否开启了游戏的数值冻结                                               |
