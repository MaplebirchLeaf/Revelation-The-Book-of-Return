# 神殿唱诗班 · 歌唱

加入唱诗班、每天练声，在周日弥撒中唱诗。熟练之后，约旦会让你领唱。你也可以在公园与酒馆表演，收取小费。

### 加入与练习

成为见习教徒、修士或司祭后，衣着得体地到**神殿大厅**，向约旦「**询问唱诗班 (0:10)**」。没有歌唱基础也能加入。

每天 **09:00–18:00**、周日弥撒之外，可以选一项 **30 分钟**的练习：

| 练习     | 效果                             |
| -------- | -------------------------------- |
| 练习换气 | 歌唱 +12，增加少量疲劳、缓解压力 |
| 练习音准 | 歌唱 +18，增加少量疲劳           |
| 排练合唱 | 歌唱 +15，增加少量疲劳、获得恩典 |

最近**两天内**练习过，周日唱诗时更容易跟上。

### 其他练习与演出

海盗船上跟唱或领唱号子、完全哈比转化后与酒馆乐师伴唱，以及在鹰塔栖木唱歌，都能练习歌唱。领唱资格所需的练习次数，通过神殿的每日练唱积累。

歌唱技能可在**角色 → 特征 → 技能**查看。哈比转化达到 **3 级**后，实际歌唱水平提高 **20%**。疲劳达到上限一半、或喝醉时，发挥各降低 **10%**。

- **公园**：白天没有下雨时，为路人表演。
- **走私者酒馆**：乐师在场时，提议演唱。
- 两处共用**每天一次**的演出机会。一场分三段，每段 **10 分钟**。可以稳住旋律、尝试转音，或邀请听众一起唱。歌唱、语文与听众的兴致会影响表现。
- 完整演出的小费约为酒馆 **£15–60**、公园 **£6–36**。可以提前收尾，领取已完成部分的小费。直接离开或被打断时，未领取的小费会失去。出色的演出还会增加善行名声。
- 在枯木逢春的房产宴会中，也可以为宾客唱歌，影响兴致与关系。

### 周日弥撒

周日 **11:00–13:00**，在大厅选择「**随唱诗班参与弥撒 (1:00)**」。依次唱三节，每节 **20 分钟**。

跟着旋律唱较容易，和声需要更高技巧。取得资格后也能领唱。稳稳唱完一节得 **2 分**，领唱得 **3 分**，勉强跟上得 **1 分**。

完整唱完后，会受到弥撒的神圣影响：完整天使缓解压力与创伤，堕天使和完整恶魔则增加压力、创伤与疼痛，堕天使还会增加更多纯洁。

当天只能参加一次弥撒。完整唱完并听取约旦的评价，才记录次数、恩典与报酬。表现良好也会提升约旦的好感。

### 领唱与报酬

完成一场弥撒时，同时满足以下条件，即可取得领唱资格：

- 完成 **3 次日常练习**。
- 完成 **3 次弥撒唱诗**，本次也计入。
- 基础歌唱达到 **B 级（600）**。
- 本次表现至少 **5 分**。

从下周起可以领唱。每次完整唱诗记下 **£70 + 每分 £20**，最高 **£250**。报酬会累积，在通过月度检查并领取神殿津贴时一同发放。暂未领到的部分会继续保留。

日志记录时间、领唱资格与待领报酬，统计中可查看练习及唱诗次数。
