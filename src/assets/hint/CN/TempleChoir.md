### 加入与日常练习

启用「神殿唱诗班」，PC 已通过入殿试炼、成为**见习教徒、修士／修女或司祭**，衣着完整，约旦已登场时，在**神殿大厅**选择「**询问唱诗班 (0:10)**」。先处理大厅当前的检查或强制剧情。

唱诗班不要求罗宾加入神殿，也没有最低歌唱等级。完成试唱即可加入，获得歌唱练习与恩典。

推荐顺序：**询问唱诗班 → 每日练习 → 周日唱诗 → 月检领取津贴 → 争取领唱**。

入职后，在大厅选择「**参加唱诗练习 (0:30)**」。开放时间为 **09:00–18:00**，每天一次，周日 **11:00–13:00** 弥撒期间暂停。选定练习后才耗时并登记，三项共用当天次数。

| 练习     | 基础歌唱与其他变化         |
| -------- | -------------------------- |
| 练习换气 | 歌唱 +12，疲劳 +1，压力 −3 |
| 练习音准 | 歌唱 +18，疲劳 +2          |
| 排练合唱 | 歌唱 +15，疲劳 +1，恩典 +1 |

在**角色 → 属性 → 技能**查看歌唱。等级沿用技能卡，从无到 S。**基础技能决定领唱资格，当前发挥决定唱诗表现**；哈比加成、疲劳和醉酒会改变当前发挥。

### 神殿以外的练唱

启用唱诗班模块即可练习，不要求入团或加入神殿：

| 原版活动                           | 基础歌唱收益              |
| ---------------------------------- | ------------------------- |
| 海盗甲板船歌：跟唱／尝试领唱       | +6／+10，领唱失误也能练习 |
| 酒吧艺人：完全哈比转化后「跟着唱」 | +10，打赏与只听音乐不计   |
| 鹰塔栖木：「唱歌 (0:30)」          | +8，大鹰没有应和时也计    |

这些活动保留原版出现条件与人物反应，不计作唱诗班排练，也没有神殿报酬。启用罗宾神殿路线后，完全哈比转化的 PC 还可在长椅为罗宾唱歌。

**哈比转化达到三级时，当前发挥提高 20%；疲劳达到上限一半或醉酒，各使当前发挥降低 10%。**技能卡显示这些变化。练习仍受技能上限与数值冻结限制。

### 周日唱诗

**周日 11:00–13:00**，在神殿大厅选择「**随唱诗班参与弥撒 (1:00)**」。这与当天普通弥撒共用一次机会，先参加其中一种，就不能再参加另一种。

1. 依次唱开场赞美诗、经文答唱、结束赞美诗，每段二十分钟。
2. 每段选择「跟随合唱」或「支撑和声」，获准后还可「领唱这一节」。三段可用不同方式。
3. 唱完三段，再听约旦评价，登记本次工作与加款。

| 方式       | 难度与评分                      |
| ---------- | ------------------------------- |
| 跟随合唱   | 要求最低，稳定唱完得 2 分       |
| 支撑和声   | 对技巧要求更高，稳定唱完得 2 分 |
| 领唱这一节 | 最考验发挥，稳定唱完得 3 分     |

勉强跟上得 1 分，没跟上不加分。**最近两天练习过**有助于发挥，疲劳与醉酒会妨碍表现。每段增加疲劳；跟上可以缓解少量压力，失误增加压力。唱错仍可继续，完整完成会增加纯洁与恩典，至少五分时增加约旦爱意。

<span class="red">开始后就占用当天弥撒机会。中途退出，没有本次加款，也不能当天重开。</span>此前累积的加款保留。

### 领唱与津贴

在完整唱诗结束时，同时满足以下条件，约旦会批准领唱：

- 完成至少 **3 次日常练习**。
- 完整完成至少 **3 次唱诗**。
- **基础歌唱达到 B 级（600）**。
- 本次取得至少 **5 分**。

达标的这次唱诗计入次数，**下一次**即可领唱。哈比加成不能替代基础技能要求。

每次完整唱诗，津贴加款为 **£70 + 每分 £20**：0 分 £70、5 分 £170、6 分 £190、9 分 £250。金额先记入账册，**不会立即发到钱包**。

到期接受神殿月度检查，通过且正常获发津贴时，唱诗加款随原版恩典津贴一并领取。检查失败或恩典不足时，加款保留到之后获准领取。罗宾共同月检与三人联合月检也领取同一笔加款。

在**游戏日志 → 神殿唱诗班**查看练习次数、完整唱诗次数、领唱许可、待领金额与时段。罗宾的每周收入及枯木逢春的神殿救济基金仍各自结算。

### 找不到入口时

- **不能加入**：检查模块、神殿身份、衣着、约旦是否登场，以及大厅当前剧情。
- **没有练习**：须入职、09:00–18:00、当天尚未练习，且不在周日弥撒时段。
- **没有唱诗**：须周日 11:00–13:00，当天未参加普通弥撒或唱诗。
- **高等级却不能领唱**：核对基础技能、三次练习、三次完整工作与本次五分。
- **唱完没拿钱**：查待领加款，等月检后正常发放神殿津贴。
