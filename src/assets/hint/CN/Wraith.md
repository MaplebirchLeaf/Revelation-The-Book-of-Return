# 象牙怨灵 · 象牙项链

从湖底带走项链后，可以将它送回基座，缓和怨灵因失窃而生的敌意。

### 归还项链

带着**未出售的项链**，或从奎恩处盗回的实物，在**非血月**时潜入湖底废墟的基座房间，查看基座，选择「**将项链放在基座上**」。

至少一只手能活动，压力未满，并留有氧气时，可以将项链放下。放下会按游泳技能消耗时间与氧气。归还后会失去项链，若它仍可出售，也会放弃 **£2,000**的卖价。

- **首次归还**：解除盗取项链造成的痴迷下限。苍白后代没有死亡或被卖掉、相关愤怒已经平息时，痴迷再减少 **10**。
- **再次拿走**：已结识的怨灵痴迷重回 **20**。之后再归还，最多只减少 **1**。
- 苍白后代的旧怨、追猎与附身仍需另行处理。

营业时可以向格威岚请教，归还后也能告知结果，每次交谈 **10 分钟**。

### 从奎恩处取回

听温特说明去向、看见办公室里的项链、亲自交给奎恩，或见证潜水队取走项链后，可以白天到**市长办公室候见室**寻找机会。项链需在奎恩手中。

先观察访客 **15 分钟**，再趁奎恩在楼下接待时行动。前台、摄像头与展示盒的诡术要求分别为 **600／500／900**。体能达到上限一半也能砸盒，但会触发警报，增加盗窃与毁坏财物的犯罪记录。

每天可尝试一次，每一步都能撤退。盗回的项链不能再次出售，带回湖底归还后才能继续后续。

### 湖畔回访

首次归还**三天后**，在湖岸选择「**在湖边坐下，等一会儿**」。需先遇见过怨灵，并等湖岸恢复平常的活动。血月、追猎、附身和苍白后代的旧怨会阻止相遇。

静坐 **15 分钟**、期间未被打断，痴迷减少 **1**。每次回访至少间隔**三天**。痴迷为零时仍能完成尚未结束的故事，之后的普通回访需要仍有痴迷。

### 归还之后

1. 完成一次平静的回访后，回孤儿院自己的床上选择「**闭上眼睛，休息一小时**」。平日睡在这里时，也可能做这个梦。
2. 梦中可以观察、靠近、说话或试着醒来。经历过「分裂」时，会想起那次相遇。
3. 醒后可与有空的罗宾、在神殿祈祷的悉尼，或营业时的格威岚谈谈。找其中一人即可，也可以保密，独自回岸边想一想。
4. 与上次回访间隔三天后再到湖边。完成这次相遇，会得到一次宽慰。

再次拿走项链会打断平静相处，归还后才能继续。

### 穿戴项链

从湖底拿走或从奎恩处盗回项链时，会获得可穿戴的颈饰。归还、卖给博物馆或卖给奎恩时，也会失去它。

首次归还后，森林商店解锁同款仿制颈饰，价格 **£2,000**，可以作为服装购买穿戴。
